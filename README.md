# PayAnalytics Local Setup Walkthrough

Welcome to **PayAnalytics**! This guide will walk you through cloning the project, setting up the database, and running both the backend and frontend services on your local machine using MySQL.

---

## 📋 Prerequisites

Before starting, ensure you have the following installed on your machine:
*   **Git**
*   **Node.js** (version 18 or higher)
*   **Python** (version 3.11 or higher)
*   **MySQL Database Server** (e.g., MySQL Community Server or via XAMPP)

---

## 🚀 Getting Started

### Step 0: Clone the Repository

First, clone the PayAnalytics codebase to your local machine using Git, then change your working directory into the project root:

```bash
